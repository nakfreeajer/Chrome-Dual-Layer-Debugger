## 2026-09-29 — V0.1D Run / Trace Identity — ACCEPTED
- Baseline: `6c737e981901c79d3425c5b3288c4b8b737761e5`.
- Implementation: `b14fda0db3b4d150064c91eab86dfdda19b6cd1f` (`Add explicit timeline run identity`).
- Added required `runId` to newly generated `TraceEvent` records.
- Each `Timeline` owns one immutable run identity, generated by Node `crypto.randomUUID()` by default or deterministically injected for tests.
- `Timeline.create()` injects the run identity into every event; `Timeline.append()` rejects events from another run.
- Per-run numbering intentionally remains `EVENT-000001` onward, so `(runId,eventId)` is the cross-run event identity.
- CLI now prints the active Run ID.
- JSONL append format is unchanged; historical V0.1C JSONL was not rewritten or migrated.
